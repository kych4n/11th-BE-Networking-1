## 🏎️ 자동차 경주 기능 명세서

### 입력

1. 자동차들의 이름
    1. 이름은 쉼표로 구분한다.
    2. 각 이름은 5자 이하이어야 한다.
2. 이동 시도 횟수
    1. 횟수이므로 자연수이어야 한다.

### 출력

1. 각 차수별 실행 결과
    1. 자동차마다 `자동차 이름 : 위치` 형식으로 출력한다.
2. 최종 우승자 안내 문구
    1. `최종 우승자 : 자동차 이름` 형식으로 출력한다.
    2. 최종 우승자가 여러 명인 경우 쉼표로 구분하여 출력한다.

### 비즈니스

1. 전진 시도
    1. 0에서 9 사이에서 무작위 값을 구한 후, 무작위 값이 4 이상일 경우 전진한다.

### 예외 처리

1. 사용자가 잘못된 값을 입력할 경우
    1. `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.
